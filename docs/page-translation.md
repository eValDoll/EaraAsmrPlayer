# 页面翻译

在「设置 → 翻译配置 → 页面翻译」中仅选择目标语言，支持简中、繁中、日文、英文、俄语、韩语，默认为简中。源语言内置自动识别，不提供选择栏，也不增加相关说明文字；升级后忽略旧的源语言设置。

本地库、在线搜索、热门收听主页面的 header 右上角、「任务管理」左侧提供无底色翻译图标。专辑详情页右上角提供翻译按钮，复用「编辑 RJ 号」按钮的半透明底色、边框和白色图标，不显示任务管理入口；本地专辑保留原有编辑按钮。单击开启页面翻译，处理期间图标显示转圈动画，完成后变为恢复原文图标；再次点击直接恢复原文，处理中点击会取消当前请求。没有弹窗或常驻说明小字。设置中仅保留语言选择、自动翻译开关与清空缓存操作。翻译范围包含作品标题、社团、标签、本地与在线目录的目录名、文件名和路径导航中的目录名称。文件扩展名、作品编号、声优名、播放地址及搜索/筛选使用的原始值保持不变。

页面翻译使用 Google 公共在线翻译接口，无需 API Key，与 DeepSeek 字幕翻译互相独立。该接口并非具有可用性承诺的 Google Cloud Translation 服务，可能受网络、限流或服务调整影响。待翻译文本会发送至 Google，失败时保留原文并通过应用现有的消息组件短暂提示；不会自动切换付费服务。需要重试时先恢复原文，再点击翻译，仍遵守限流冷却。

翻译由页面统一调度：页面中的文本组件只登记原文，收集窗口为 180 毫秒。待翻译内容按语言对去重并查询缓存，缺少译文的文本以重复 `q` 字段放进同一个 POST 请求，调用 Google `/translate_a/t` 批量接口。当前采用每批最多 50 条、总计最多 4000 个 UTF-16 字符的保守客户端上限；未超限时只发一次请求，超限才拆批。滚动后只合并提交新出现且未命中缓存的文本，不预先遍历整个本地库。

返回结果按数组位置对应原文，并严格校验条数和文本类型；不拼接换行后猜测拆分，也不在批量失败时退回逐条请求。重复标题、社团和标签只提交一次。文件扩展名在回填时恢复。后续批次失败时保留前面成功的译文，其余继续显示原文。

所有页面翻译请求在网络层固定使用 `sl=auto`。服务对每条文本检测语言并直接返回译文，不另外发送检测请求，混合语言页面也可按原文位置回填。请求、设置及页面状态不再接受可配置的源语言。公共批量接口实测四条日文、英文、俄语、韩语文本一次请求返回 HTTP 200 和四组「译文、检测语言」。

译文按原文和目标语言缓存。磁盘沿用 `auto:目标语言` 分区，可复用已有自动识别译文，不会读取旧的指定源语言译文。磁盘最多保留 3000 条，内存最多保留 1000 条，设置中可以清空。网络和磁盘操作在后台执行，磁盘译文按批次在事务中写入；离开页面、切到后台、切换目标语言或恢复原文时取消当前批次。批次串行且相邻请求至少间隔 250 毫秒；限流时尊重 `Retry-After` 秒数并至少冷却一分钟；Google 异常流量拦截单独提示网络原因并至少冷却五分钟，冷却本身不能保证解除拦截。

```powershell
$env:ANDROID_SERIAL = "emulator-5554"
.\gradlew-local.bat :app:testReleaseUnitTest --tests "com.asmr.player.translation.*"
.\gradlew-local.bat :app:installRelease
.\gradlew-local.bat :baselineprofile:assembleBenchmarkRelease
```

`libraryPageTranslationFrameTiming` 使用设备现有本地库，覆盖开启页面翻译后滚动的实际路径，复用既有慢拖动/快速滑动手势，并保留应用数据和当前编译状态。请准备包含足够作品的测试库，使用指定串号覆盖安装测试 APK，并直接执行该方法的 instrumentation；避免在个人设备上使用可能卸载目标应用的 connected 测试任务。测量时需记录网络、缓存命中和设备刷新率；公共服务限流时的结果只能代表失败回退路径，不能视为成功翻译时的性能结论。没有连接高刷新率设备并完成 Release/benchmark 测量时，不声称达到 P99 ≤ 8.3 ms。
