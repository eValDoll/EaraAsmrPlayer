# 播放页多行字幕

入口：设置 → 歌词 → 播放页歌词 → 多行完整显示。默认关闭，保留原有显示方式；开关和高亮字号一起保存。

此开关同时作用于竖屏经典布局和悬浮歌词原有的单行滚动字幕。开启后，当前句自动换行，不使用横向跑马灯或省略号。手机和平板横屏播放页、独立歌词页及展开式主页继续使用原有歌词显示方式。

- 竖屏按可用高度和字号预留固定字幕区，上限为上半页可用高度的 45%。必要时缩小封面，预留尺寸不依赖字幕文字或行数。
- 超长句只在字幕区内纵向滚动，细滚动条提示还有内容。字幕区不设置额外按钮或全文弹窗，全部空间用于正文。
- 切句使用固定容器中的淡入淡出，新的字幕从句首显示；正文测量只在内容或布局参数变化时发生，滚动条在绘制阶段读取滚动位置。

悬浮歌词复用同一个持久化开关，切换即时生效。背景固定为全透明，不提供透明度滑条，也不再读取或保存旧的透明度设置。多行悬浮区域按三行字号预留高度，最多占屏幕高度的 45%，大小不随字幕长短变化。区域始终位于屏幕内，超长正文可上下滑动，字幕区域边缘可拖动垂直位置；点击穿透开启时继续透传手势，需关闭穿透才能滑动阅读。切句重置阅读位置，取消上一句的惯性滚动。关闭多行开关后恢复单行跑马灯和原有拖动方式，背景仍然全透明。

`FloatingLyricsViewTest` 覆盖真实换行、固定高度、字号与紧凑区域、开关回退、切句滚动复位及正文滑动与边缘拖动；同时验证实际系统悬浮窗口的位置限制、点击穿透和原窗口内的显示模式切换。`MultilineLyricsBenchmark` 同时覆盖悬浮字幕的标准和紧凑高度切句场景，使用实际悬浮正文组件，但不代表系统悬浮窗口的完整合成性能。

## 验证

单元测试覆盖默认设置及短屏封面空间分配。设备测试 `NowPlayingLyricsPersistenceTest` 覆盖设置保存，测试后恢复原设置。设备界面测试 `NowPlayingMultilineLyricsTest` 覆盖真实换行、正文完整性、长短句切换时相邻控件坐标、紧凑高度与大字号下的滚动及切句后的滚动位置复位。

`MultilineLyricsBenchmark` 使用 Release 派生的 benchmark 构建，分别测量常规高度和 72dp 高度／36sp 字号下的长短句切换。场景不清除应用数据，不写入媒体库，也不修改播放队列。此测试隔离字幕组件，不代表整个播放页或导航性能。

项目验证必须通过 `gradlew-local.bat`，最终使用 `:app:installRelease` 安装正式构建。

### 2026-09-07 初版设备测量（移除操作栏之前）

设备型号 23078RKD5C，Android 16。测量时确认字幕基准场景在前台且实际刷新率为 120Hz。使用 `CompilationMode.Full`，每种场景执行五轮。

| 场景 | gfxinfo P99 帧耗时（五轮中位数） | 五轮 P99 范围 | 卡顿比例中位数 |
| --- | --- | --- | --- |
| 常规高度，24sp | 17ms | 16–20ms | 0.59% |
| 72dp 高度，36sp | 18ms | 14–19ms | 0.33% |

这些结果尚未达到项目 8.3ms 的 P99 目标。该设备的 Perfetto 采集未返回 RenderThread slices，故采用项目既有的 `FrameTimingGfxInfoMetric`；不能将这些数值等同于 Perfetto 的 CPU 帧耗时，也不能据此宣称全播放页性能达标。

设备上的五项功能测试全部通过，包括设置开关与字号的双向保存、真实字体换行及正文完整性、长短句切换时相邻控件坐标稳定、紧凑高度与大字号下的展开入口、全文阅读保留以及相同文字下一句的滚动复位。

初版十一项 Release 单元测试通过，`:app:installRelease` 成功安装到该设备，并检查了正式版本中的设置入口。安装包、测试 XML、测量 JSON 及设置截图保存在本工作目录的 `.dev-data/multiline-validation/`，构建缓存已清理。

后续按反馈移除了字幕区底部和侧面的操作按钮、全文弹窗及相关状态，保留原字幕区尺寸与点按字幕进入歌词页的交互。上述性能数据来自移除前的版本，不代表此修订的重新测量结果。

竖屏修订（移除操作栏并限定播放页的适用布局）已通过 `:app:installRelease` 构建并安装到连接设备；安装包已更新。当时同步调整了界面回归测试，未重新运行设备测试或性能测量。
